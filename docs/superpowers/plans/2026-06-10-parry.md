# Rebanada 4 — Sistema de Parry — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dar a cada superviviente un parry por cacería: cuando el fantasma intenta matarlo, una tirada por pericia (valentía, penalizada por pánico) puede bloquear — éxito aturde al fantasma 3s (sin kill, sin habilidades, ralentizado) y el superviviente sobrevive huyendo; fallo = muerte. Contrajuego: re-atacar a quien ya gastó su parry.

**Architecture:** Lógica pura `parryChance`/`rollParry` en `js/logic.js` (testeable con rng inyectable). El estado (`parryUsed` por agente, `stun` del fantasma) y los efectos (gating de kill/habilidades, ralentización, feedback) viven en `js/main.js`, enganchados al kill path de la cacería de R3.

**Tech Stack:** JS vanilla ESM, Three.js 0.160 por CDN (sin build), Node test runner (`node --test`), verificación manual en navegador vía CDP/headless.

**Spec:** `docs/superpowers/specs/2026-06-10-parry-design.md`.

- [ ] **Step 3: Implementación**

Añade al final de `js/logic.js`:

```js
// Probabilidad de parry (0..1) según pericia (valentía). El pánico la hunde.
export function parryChance(bravery, panic, p = { base: 0.25, perBravery: 0.5, panicMul: 0.3 }) {
  const c = p.base + p.perBravery * bravery;
  const v = panic ? c * p.panicMul : c;
  return v < 0 ? 0 : v > 1 ? 1 : v;
}

// Tirada de parry: true si éxito. rng() en [0,1).
export function rollParry(chance, rng = Math.random) {
  return rng() < chance;
}
```

Expected: PASS (parry + el resto verde).
